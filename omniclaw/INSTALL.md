# Jarvis on Mac — install

Pre-reqs: macOS 13+, Homebrew, ~10 min of patience.

## 1. System bits

```bash
brew install --cask tailscale
brew install python@3.12 node
```

## 2. OpenClaw

```bash
npm install -g openclaw@latest
openclaw onboard          # one-time wizard; pick your LLM provider, etc.
openclaw doctor           # confirms your environment is clean
```

## 3. This repo

```bash
cd /path/to/Personal\ Assistant
python3 -m venv .venv
.venv/bin/python -m pip install -r omniclaw/requirements.txt
```

The repo doesn't need to be installed as a Python package; the launchd
job and CLIs reference it by absolute path.

## 4. Accessibility permission

```bash
.venv/bin/python omniclaw/tools/macos_ax.py screen-size
```

The first run pops up the Accessibility permission dialog. Grant it for
`python3` (or for your shell binary if the dialog asks for that).
Output should be `{"ok": true, "width": ..., "height": ...}`.

## 5. Keychain secrets

```bash
# OpenAI key for OpenClaw's Talk mode (BYOK)
security add-generic-password -s jarvis -a OPENAI_API_KEY -w "sk-..."

# Peer shared secret (will be regenerated by `pair show` if missing)
security add-generic-password -s jarvis -a PEER_SHARED_SECRET -w "$(openssl rand -base64 32)"
```

Verify they're readable:

```bash
security find-generic-password -s jarvis -a OPENAI_API_KEY -w
```

## 6. OpenClaw configuration

Open `~/.openclaw/openclaw.json` (or create it) and merge in the
keys from `omniclaw/workspace_template/openclaw.json.snippet`. The
top-level keys you need are `talk`, `voicewake`, and `tools.exec.approval`.

Read the snippet for inline `_note` comments explaining each rule.

## 7. Workspace bootstrap files

```bash
mkdir -p ~/.openclaw/workspace
cp omniclaw/workspace_template/AGENTS.md  ~/.openclaw/workspace/
cp omniclaw/workspace_template/SOUL.md    ~/.openclaw/workspace/
cp omniclaw/workspace_template/USER.md    ~/.openclaw/workspace/
cp omniclaw/workspace_template/TOOLS.md   ~/.openclaw/workspace/
```

Edit `~/.openclaw/workspace/USER.md` and put your real name, contacts,
preferences. The agent reads this file at session start.

## 8. Peer daemon (launchd)

```bash
# Patch the placeholders in the plist with real paths:
REPO_PARENT=$(pwd)
PYTHON_BIN=$(.venv/bin/python -c "import sys; print(sys.executable)")
sed -i '' \
    -e "s|__REPO_PARENT__|$REPO_PARENT|g" \
    -e "s|__PYTHON_BIN__|$PYTHON_BIN|g" \
    -e "s|__HOME__|$HOME|g" \
    omniclaw/launchd/ai.jarvis.peer.plist

# Install + start:
mkdir -p ~/Library/LaunchAgents ~/.jarvis
cp omniclaw/launchd/ai.jarvis.peer.plist ~/Library/LaunchAgents/
launchctl load ~/Library/LaunchAgents/ai.jarvis.peer.plist
```

Verify:

```bash
.venv/bin/python omniclaw/tools/peer_cli.py status
# -> {"ok": true, "device_id": "mac-xxxx", "ws_port": 18790, ...}

.venv/bin/python omniclaw/tools/peer_cli.py verify
# -> {"ok": true, "checks": {"daemon_alive": true, "sock_perms_ok": true,
#     "ping_self": true, ...}}
```

## 9. Tailscale

```bash
tailscale up
tailscale status                   # confirm you have a tailnet
tailscale status --json | jq -r .Self.DNSName   # your MagicDNS hostname
```

## 10. Pair with the phone (once you have the APK)

```bash
.venv/bin/python omniclaw/tools/peer_cli.py pair show --qr
```

Scan the QR with the Jarvis app on the phone. It will save peer.json on
both sides. Confirm:

```bash
.venv/bin/python omniclaw/tools/peer_cli.py ping
# -> {"ok": true, "rtt_ms": 23, ...}
```

## 11. Talk to it

In any OpenClaw chat, or via the wake word "Hey Ben":

> "Open Cursor and create a new file."
> "Take a photo with my phone and put it on the desktop."
> "Read me my unread WhatsApps."
> "Send dad the design doc on WhatsApp."

The agent reads `AGENTS.md` + `SOUL.md` + `USER.md` + `TOOLS.md` and
the per-skill files (`skills/peer/SKILL.md`, `skills/macos-accessibility/SKILL.md`),
discovers tools via the `--json-tools` flag of each CLI, and decides what
to do.


Should print `62 passed`.

## Troubleshooting

- `daemon socket not found at ~/.jarvis/peer.sock` — daemon isn't running.
  `launchctl list | grep jarvis` should show `ai.jarvis.peer`. Otherwise
  reload: `launchctl unload ~/Library/LaunchAgents/ai.jarvis.peer.plist`
  then `launchctl load ...` again. Logs at `~/.jarvis/peer.log`.
- `no_peer_paired` — you skipped step 10 or the peer.json got deleted.
  Re-run `pair show --qr`.
- `Operation not permitted` from `macos_ax.py` — Accessibility
  permission isn't granted. Re-run step 4.
- "Hey Ben" doesn't wake — OpenClaw VoiceWake config is wrong, or the
  Porcupine model isn't loaded. `openclaw doctor` will diagnose.
- Token spend climbing fast — bump `cost_cap` in USER.md and remind the
  agent to be terse.
